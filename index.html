Big Idea

Stored program concept: data and instructions are stored in the same memory.

  • CPU fetches instructions from memory like data
  • Same system connects CPU, memory, and input/output
  • This also creates the von Neumann bottleneck

Buses (How Components Communicate)

Bus
What it carries
Direction
Address
Memory location (where to read/write)
CPU → Memory/I-O
Data
Actual data or instruction bits
Both ways
Control
Signals like READ and WRITE
CPU → Memory/I-O
Common mistake Only the data bus is bidirectional.

Memory Read

  1. Put the address into MAR
  2. Send a READ signal on the control bus
  3. Memory sends contents back into MDR
  4. CPU uses the data from MDR
Waiting…

Memory Write

  1. Put the data into MDR
  2. Put the address into MAR
  3. Send a WRITE signal on the control bus
  4. Memory stores the data at that address
Waiting…
